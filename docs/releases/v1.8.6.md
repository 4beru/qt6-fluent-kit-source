Fluent-Kit 1.8.6 completes the project's public rebrand and refreshes the
delivery path around the public Fluent-Kit repository. The release is focused
on identity, package metadata, documentation, and distribution infrastructure
rather than introducing a new component family.

## Fluent-Kit public identity

- The maintained website, Gallery, documentation, and project-facing links now
  use the `4beru/qt6-fluent-kit` public repository as the canonical project
  destination.
- Generated website and documentation references were synchronized with the
  Fluent-Kit name and public repository split.
- Native C++ and Python Gallery branding is aligned with Fluent-Kit.

## Public release delivery

- The website's latest-release lookup uses the public
  `4beru/qt6-fluent-kit` repository, so download controls can resolve public
  GitHub Release assets independently of the source/build repository.
- Gallery and PySide6 update checks now target the public release location.
- The validated website can be deployed from prebuilt CI output, keeping site
  delivery tied to the same validated WebAssembly and generated-site inputs.

## Packaging and project metadata

- Gallery and PySide6 package metadata were synchronized with the Fluent-Kit
  repository and website locations.
- Source, documentation, generated catalogs, and release metadata are aligned
  with version 1.8.6.

No new public component family is introduced by the 1.8.6 changes since 1.8.5.
